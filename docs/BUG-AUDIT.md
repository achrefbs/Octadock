# Octadock Consolidated Bug Audit

Date: 2026-07-01

This document merges the Octadock bugs found in the Codex multi-agent audit and the attached Claude/Octadock bug audit. It de-duplicates overlapping findings and keeps the actionable source references in one place.

Status note 2026-07-03: this is a historical consolidated audit. Some findings
have since been fixed or superseded. See `PROJECT-STATE.md` and `ROADMAP.md` for
current state and active priorities.

## Status Notes

- Current checkout status at consolidation time: clean.
- The attached report's "88 corrupted files / build cannot start" finding is not applicable to this checkout. That appears to describe a different or earlier working tree.
- At consolidation time, automated coverage was mostly `Octadock.Core.Tests` and
  `Octadock.Data.Tests`. The repo now also contains `Octadock.Cli.Tests` and
  `Octadock.Platform.Windows.Tests`, though interactive WPF/tray/monitor flows
  still need manual hardware verification.

## Priority Order

1. Stop UI loops and overlapping capture/session races.
2. Fix monitor/DPI/selection geometry issues that cause wrong-screen or wrong-box captures.
3. Replace the current timed scrolling prototype with a controlled scrolling session.
4. Fix hotkey, IPC, recording, and persistence correctness bugs.
5. Add Windows-layer tests so regressions are caught before manual testing.
