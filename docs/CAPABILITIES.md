# Octadock Capabilities Matrix

Last audited: 2026-07-23

Status legend:

- **Built** - implemented and wired in the app.
- **Partial** - user-visible or code-backed, but missing promised behavior.
- **Prepared** - code shape exists, but no complete user-facing flow.
- **Planned** - roadmap only.

| Capability | Entry points | Main code areas | Status | Limitations / next work |
| --- | --- | --- | --- | --- |
| Tray utility | Startup, tray icon, settings | `App.xaml.cs`, `TrayIconController`, settings | Built | Menu is regrouped (Capture submenu, Dictate, library group, app group); left-click toggles the Shelf; Pause/Resume is removed. Native Windows Forms tray menu path is confirmed working. |
| Permanent Dock | On-screen Dock capsule | `DockPill` | Built | Minimal Dock: split Capture button (Area primary; Window/Full screen/All monitors/Previous area/Timer/Scrolling Beta/OCR/Record menu), Dictate, Shelf, History, and a More menu (Clipboard, Context, Settings, Account/About, Exit). Rendered DPI/theme acceptance remains. |
| Area capture | Hotkey (`Ctrl+Shift+4` default), Dock, tray, CLI/protocol | `CaptureCoordinator`, `RegionSelectionService`, `CaptureEngine` | Built | Precision aids (dimensions + magnifier) and freeze-screen default on. Keep testing mixed-DPI overlays. |
| Previous-area capture | Dock Capture menu, tray, CLI/protocol | `CaptureCoordinator`, command parser | Built | Falls back to selection when no previous area exists. No default shortcut; assignable. |
| Fullscreen capture | Hotkey (`Ctrl+Shift+3` default), Dock Capture menu, CLI/protocol | `CaptureCoordinator`, `CaptureEngine` | Built | Single monitor prefers WGC; all-monitor uses GDI. |
| Window capture | Dock Capture menu, tray, CLI/protocol | `WindowPickerOverlay`, `WindowPicker`, `CaptureEngine` | Built | Picker overlays are per-monitor; WGC falls back to GDI/PrintWindow when needed. No default shortcut; assignable. |
| Self-timer capture | Dock Capture menu, CLI/protocol, command path | `CaptureCoordinator`, command parser, `CaptureCountdownPill` | Built | Shows a transient countdown pill after region selection and hides it before capture. |
| Capture Shelf | Shelf window/cards | `ShelfService`, `ShelfWindow`, `ShelfViewModel`, `ShelfItemViewModel`, `ShelfItemView` | Built | Accepts Octadock captures/recordings only. × is dismiss-only; permanent delete is a separate default-No confirmed route that removes file and History row. Rendered mixed-DPI QA remains. |
| Video shelf cards | Recording stop flow | `RecordingController`, `ShelfItemViewModel`, `ShelfItemView` | Built | Recordings without an extracted thumbnail show a visible poster plate, play affordance, and duration. Videos cannot be annotated. |
| Clipboard copy | Shelf/history/editor | `WpfClipboardService` | Built | Clipboard failures need stronger surfaced error states. |
| Drag-out | Shelf/editor | Shelf/editor view models | Built | Temp export cleanup needs audit. |
| Local history | History window, retention timer | `HistoryViewModel`, repositories, `RetentionService` | Built | Includes type/search/deleted/date filters; explicit Annotate action for image captures. Legacy `pins` rows are inert. |
| Annotation editor | Post-capture, Shelf, History (captures and `.octadock` projects only) | `AnnotationEditorWindow`, `EditorViewModel`, `AnnotationService`, renderer | Built | `OpenAsync(CaptureRecord)` records an honest `Annotated` action; missing/corrupt sources fail visibly. Arbitrary-file/clipboard annotation entries are removed. |
| OCR | Dock Capture menu, CLI/protocol, file | `OcrService`, `OcrHistoryRecorder`, `WindowsMediaOcrProvider` | Partial | Region OCR and file OCR work; region grabs create `OcrSource` history rows with recoverable text. File OCR does not create history rows yet. Windows AI/Tesseract remain placeholders. |
| Scrolling capture | Dock Capture menu, CLI/protocol | `ScrollingCaptureEngine`, `ScrollingSessionPill` | Partial | Beta: manual vertical only; auto-scroll and horizontal are rejected. Needs adversarial live testing. |
| Screen recording | Tray, Dock Capture menu, CLI/protocol | `RecordingController`, `MediaFoundationRecordingEngine`, `RecordingPill` | Partial | Beta: MP4 video with optional microphone (WASAPI) and system/app (loopback) AAC tracks as explicit Settings opt-ins (default video-only). Sample-count clock, finalization validation, crash/device-loss/disk-pressure recovery, and no false success are built. Real hardware/audio-device acceptance remains. Camera, click/keystroke overlays, GIF, trim/compress are planned. |
| Automation CLI/protocol | `octadock.exe`, `octadock://` | `CommandParser`, `CommandDispatcher`, IPC | Built | Settings toggles gate dispatch before parsing. Successful capture JSON/IPC replies include the exact durable `captureId`; pre-artifact cancellation fails truthfully. Protocol blocks microphone-starting/local-only commands. Removed features (`pin`, `open`, `open-annotate`, `open-from-clipboard`, `add-shelf-item`, `all-in-one`) keep tombstones: non-zero "feature removed" errors, absent from help. |
| Context | Dock More menu/tray/CLI, shelf add-to-context, Context window, Use with AI source | `ContextService`, `ContextRepository`, `ContextViewModel`, `ContextWindow`, `ContextExport` | Partial | Persistent packages, snapshot/reference ownership, notes/reorder, exact per-item include/export, safe folder/zip export, and verified references are built. Missing/changed/unseen references fail closed. Rendered workflow acceptance remains; MCP is deferred beyond beta. |
| Dictation / STT | Dock Dictate action, global shortcut (`Ctrl+Shift+2` default), CLI | `DictationController`, `DictationPill`, audio/STT providers, shortcuts, command parser | Partial | Local Parakeet default, explicit local Whisper fallback, OpenAI only via `OCTADOCK_OPENAI_API_KEY`. State machine (Idle/Preparing/Listening/Transcribing/Inserting/AwaitingReview/Completed/Discarded/Cancelled/Failed) with distinct pill phases, insertion honesty, review-before-insert mode, microphone picker, model consent with provider/size/storage, model integrity quarantine, and device-loss surfacing. 74 deterministic rows plus a versioned SAPI-corpus benchmark baseline are recorded; live device/accent/language QA remains. Windows Speech fallback not shipped. |
| Read aloud | Tray, `octadock read`, Use with AI result | `ReadAloudService`, `WindowsTtsProvider`, `ElevenLabsTtsProvider`, `SentenceChunker`, `ReadingPill` | Built | Verbatim by default with Windows voices. `--explain` opens Use with AI with an investigation goal; results retain Read aloud. Ambient screen discovery is out of beta scope. No default shortcut; assignable. |
| Use with AI | Tray, Shelf, Context, selected History/Clipboard row, `octadock ai` / `agent` / `handoff` and legacy aliases | `AgentReviewLaunch`, `AgentWorkflowCatalog`, `AgentWorkspaceWindow`, `AgentWorkspaceViewModel`, `AgentPacketBuilder`, `AgentPacketExportService`, `AgentCliRunner`, `SkiaVisualComparisonService` | Partial | Every entry opens one source-bound, owner/topmost-aware, fail-closed review with exact evidence and owned-temp rollback. The deterministic packet/redaction/read-only CLI engine remains explicit and provider-named. Rendered focus/close/mixed-DPI acceptance remains; write execution, pixel redaction, MCP, and local-model destinations are not shipped. |
| Settings | Settings window | `SettingsWindow`, `SettingsViewModel`, `SettingsSections` | Partial | Capture screenshots page split Basic (save folder, format, cursor, selection incl. freeze + precision aids) vs Advanced (filename template, JPEG quality, shadow/frame, monitor behavior, fixed size/aspect, timer, manual vertical scrolling Beta); dictation, recording audio opt-ins, voice, library, system, Account & Billing, clipboard, and read-aloud settings exist. AI/MCP/upload settings are still missing. |
| Licensing/trial gate | First-run, Settings, tray, Dock, CLI/protocol activation | `LicenseStateService`, `LicenseGate`, `ActivationService`, settings/tray UI | Partial | 14-day local trial, signed entitlement, activation UI/deep link, and feature gates are wired. A distinct entitlement replacement is confirmed, but deletion/replay resistance awaits an approved offline-trial policy. Production host/KMS/Stripe/legal are external gates. |
| License service / admin health | HTTP service under `services/license-service` | `Octadock.LicenseService`, repositories, Stripe/signing services | Partial | Webhook, activation, trust anchor, authenticated admin health, alerts, and optional reconciliation are built. Public health is liveness-only; admin metrics fail closed without an `X-Admin-Token`, return `Cache-Control: no-store`, and webhook responses expose no license material. Key delivery, full admin UI, production network auth/keys, support email, and commercial operations are incomplete. |
| Update check | Core update service | `ReleaseVersion`, `UpdateManifest`, `UpdateCheckService` | Prepared | Signed-manifest verification exists, but the manifest host, signing key, UI flow, and auto-update installer are not built. |
| Crash reporting | Settings, exception handlers | `CrashReportService`, `App.xaml.cs` | Built | Saves local redacted JSON reports only when enabled. No upload/telemetry transport exists. |
| Clipboard history | Dock More menu, tray, CLI/protocol, Settings | `ClipboardMonitor`, `ClipboardHistoryService`, `ClipboardHistoryWindow`, repository | Built | Local text/image clips with provenance, dedupe, favorites, search/filter, copy/delete/clear, trimming, and selected-row Use with AI are built. Fresh settings default off; first run persists explicit enable/decline; monitoring can be paused in Settings and retained clips cleared. Live WPF/Win32 verification remains. No default shortcut; assignable. |
| Text transforms | Tray, `octadock open-text-tools` | `TextTransforms`, `TextToolsWindow`, `TextToolsViewModel` | Built | Local transform toolbox is wired; diff-two-clips remains open. |
| Upload/share | Command/action model | `PostCaptureAction.Upload`, docs | Planned | No upload providers yet. |
| Command palette | Roadmap | command parser foundation | Planned | Needs a new host surface; the former all-in-one HUD was removed on 2026-07-23. |
| Code screenshot beautifier | Roadmap | Annotation/export foundation | Planned | Needs syntax highlighting and frame/padding presets. |
| Snippet/prompt library | Roadmap | n/a | Planned | Should integrate with paste-at-cursor and Context. |
| Additional agent destinations | Roadmap | Agent Packet + destination-runner foundation | Planned | MCP, local models, and any write-enabled agent mode need separate permission/capability profiles; the current CLI handoff is intentionally analyze-only. |
| MCP server | Roadmap | command/service foundation | Planned | Expose local Octadock context after permission/redaction design. |
| Advanced recorder | Roadmap | recording foundation | Planned | Camera overlay, click/keystroke display, GIF, trim/compress. Microphone and system/app audio shipped 2026-07-23. |
| Distribution | Release script, website placeholders | `build/release.ps1`, `web/`, version files | Partial | Self-contained single-file win-x64 zip packaging exists. Installer/MSIX, code signing, SmartScreen, auto-update host, live DNS/download URL, and clean-VM release matrix remain open. |
