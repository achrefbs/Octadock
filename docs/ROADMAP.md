# Roadmap

The current product contract is [local software](LOCAL-SOFTWARE.md).

1. Complete manual native acceptance for scrolling, monitor changes, interactive dock drag, microphones and recordings.
2. Review and publish the free/local source and portable release; configure working GitHub Actions and choose a signing approach.
3. Improve scrolling capture diagnostics for unmatched/animated content and consider automatic scrolling as a separate feature.
4. Continue accessibility, performance and long-session checks.

There is no paid tier, hosted account system, cloud speech integration or activation server in this roadmap.
