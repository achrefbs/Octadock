# Wargames Archive

The folders here preserve dated adversarial research, prompts, execution plans,
and evidence. They are useful inputs, but they are not current implementation or
execution authority. Individual files intentionally retain the claims and status
language from the date they were produced.

Use `../PROJECT-STATE.md` and `../CAPABILITIES.md` for as-built truth,
`../PRODUCT-STRATEGY-2026-07.md` for current product decisions, and
`../ROADMAP.md` for the only live work queue. When a wargame conflicts with one
of those files, the current source-of-truth document wins.
