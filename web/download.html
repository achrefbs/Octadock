About this preview

This is an unsigned alpha preview. Windows may show a SmartScreen warning. Check the source and checksum before deciding whether to run it. A signed installer is not available yet.

Verify your download

Compare the SHA-256 of your installer with SHA256SUMS.txt. In PowerShell, run this from the folder containing the file:

Get-FileHash .\Octadock-0.3.0-alpha.2-Setup.exe -Algorithm SHA256

Your data stays put

The app installs to %LOCALAPPDATA%\Programs\Octadock. Captures, history and settings stay separately in %LOCALAPPDATA%\Octadock. Uninstalling the app leaves that data in place.

Quit Octadock before updating. Run the newer installer over the same location. There is no automatic updater.

Before you start

  • Dictation needs a local Parakeet or Whisper model imported in Settings → Voice.
  • Scrolling capture and recording are Beta. Scrolling is manual and vertical; microphone and system audio are opt-in.
  • The Context window may need reopening after you add a capture.
  • This release is for Windows x64. Native ARM, macOS and Linux builds are not included.
