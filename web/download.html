Download Windows ZIPRelease notes

This is an unsigned alpha preview. Capture, annotation, OCR, history and local exports are included. No account, subscription or separate .NET installation is required.

Install and launch

  1. Download the ZIP and choose Extract All in Windows.
  2. Open publish → octadock inside the extracted folder and run Octadock.exe.
  3. Complete the welcome screen. Use the dock or press Ctrl+Shift+4 to capture an area.

Windows may display a SmartScreen warning because the build is unsigned. Check that you downloaded from this release and verify its checksum before deciding whether to run it. A signed installer is not available in this release.

Verify your download

Compare your ZIP's SHA-256 with SHA256SUMS.txt. In PowerShell, run this command from the folder containing the ZIP:

Get-FileHash .\Octadock-0.3.0-alpha.2-windows.zip -Algorithm SHA256

Before you start

  • Dictation needs a supported Parakeet or Whisper model imported from your disk in Settings → Voice. Octadock does not download models.
  • Scrolling capture and recording are Beta. Scrolling is manual and vertical; microphone and system audio are optional.
  • The Context window may need to be reopened after adding a capture. Saved items and exports remain available.
  • This release is for Windows x64. macOS, Linux and native Windows ARM builds are not available.

Updating and your files

Quit Octadock before running a newer version from a separate extracted folder. Your captures, settings and history remain in %LOCALAPPDATA%\Octadock. There is no automatic updater.
