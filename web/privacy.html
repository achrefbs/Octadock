Local software

Your work stays on this PC

Octadock runs without an account or a connection to an Octadock service. It has no telemetry, automatic updates, remote AI runner, or cloud speech providers.

Local storage

Captures, annotations, recordings, history, settings and logs are stored under %LOCALAPPDATA%\Octadock. Context bundles are exported to a folder you select. Clipboard history is off by default.

Voice processing

Dictation requires a local model imported through Settings. Parakeet and Whisper run on this PC. Read-aloud uses installed Windows voices.

Your choice of folders

If you export to a folder managed by a separate sync or backup application, that application controls what it uploads. Octadock does not upload the files.

This website

Website assets are served by the website host, which receives normal page requests. There are no analytics, third-party fonts or tracking scripts. External links open only when selected.
