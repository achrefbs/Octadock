16 SEPTEMBER 2026 · WINDOWS X64

0.3.0-alpha.2

The free, local Octadock preview. Now available as a normal Windows installer, with a portable ZIP if you prefer.

Included

Capture areas, windows or displays, annotate images, extract text, keep local history and export Context bundles. Optional dictation uses models imported from disk; read-aloud uses installed Windows voices.

Fixed in this build

  • The welcome screen stays visible in the taskbar during startup.
  • Text annotations open one inline editor and commit when focus changes.
  • Lines and arrows preview as you draw and let you move either endpoint.
  • Image export avoids cross-thread decoder metadata errors.
  • Dock menus close before region capture begins.
  • The native SQLite dependency is updated to 2.1.13.

Installer packaging

The Setup executable contains the same reviewed application as the portable release. It installs for the current user and adds a Start menu shortcut. Uninstalling leaves captures, history and settings in place.

Known limits

  • The application and installer are unsigned alpha software.
  • Scrolling capture and recording, including optional audio, remain Beta.
  • Context items may require reopening the window to refresh.
  • Protected, minimized or special GPU windows may refuse capture.
  • No automatic updater, GIF export, upload provider or native macOS/Linux/ARM package is included.
