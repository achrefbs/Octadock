Windows portable preview · 16 September 2026

0.3.0-alpha.2

Free capture tools that stay on your PC

Capture areas, windows or displays, annotate images, extract text, keep local history and export Context bundles. Optional dictation uses models imported from disk; read-aloud uses installed Windows voices. No account, telemetry, cloud provider or automatic updater.

Included fixes

  • The welcome screen stays visible in the taskbar while startup waits for it.
  • Text annotation opens one inline editor and commits safely when focus changes.
  • Lines and arrows preview during drawing and let you move either endpoint.
  • Image export avoids cross-thread decoder metadata errors.
  • Dock menus close before a region capture starts.
  • The native SQLite dependency is updated to SQLitePCLRaw 2.1.13.

Known limits

  • This is an unsigned alpha for Windows x64. There is no signed installer.
  • Scrolling capture is manual, vertical and Beta. Recording and optional audio remain Beta.
  • Context items may not refresh until the window is reopened.
  • Some protected, minimized or GPU-rendered windows cannot be captured.
  • No GIF export, pinning, upload provider, macOS or Linux application is included.
